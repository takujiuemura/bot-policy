プライバシーポリシー / Privacy Policy

このアプリは、運営者が自分で管理するYouTubeチャンネルに、自分で作った動画をアップロードするためだけに使う個人用のツールです。

  • 使うGoogleの権限は、YouTubeへの動画のアップロード（youtube.upload）だけです。
  • 運営者以外の人のデータを集めたり、保存したり、第三者に渡したりすることはありません。
  • ログイン情報は運営者のパソコンの中にだけ保存され、外部に送られることはありません。

This application is a personal tool used only by its operator to upload videos the operator created to YouTube channels the operator owns. It requests only the youtube.upload scope. It does not collect, store, or share any data about other users. Credentials are stored only on the operator's own computer.

お問い合わせは、各YouTubeチャンネルのコメント欄からお願いします。 / For questions, please use the comment section of the YouTube channels.
